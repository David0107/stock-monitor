# 🥬 炒股韭菜王 | 中美双市场 MA120 均值回归监控

> **别人恐慌我贪婪，不到买点绝不出手。**  
> 基于 GitHub Actions + 静态网页构建的零成本自动化量化监控看板，每日自动抓取大A半导体、跨境纳指 ETF、美股科技七姐妹及核心宽基行情，计算 120 日均线（MA120）偏离度与分批买卖信号。

🔗 **在线监控看板**：[https://stock-monitor.dip-buyer.workers.dev](https://stock-monitor.dip-buyer.workers.dev)

---

## ✨ 核心功能

- **🇨🇳 大A & 🇺🇸 美股双市场切换**：支持一键切换查看 A 股与美股监控池，自动适配红涨绿跌与绿涨红跌习惯。
- **🌡️ 大盘基准温度计**：顶部实时展示上证指数、科创50、纳斯达克、标普500的 MA120 偏离度，辅助判断系统性风险。
- **🎯 差异化均值回归阈值**：针对高弹性科技股与低波动宽基 ETF 分别设定安全边际（买点1 / 买点2极值补仓 / 卖点止盈）。
- **📊 可视化区间刻度条**：直观展示当前股价在 `[买点2 → 卖点]` 区间内的所处位置。
- **🧮 韭菜补仓试算器**：点击表格任意当前价格，即可快速模拟补仓后的综合摊薄成本与回本所需涨幅。
- **📅 历史快照回溯 & 一键复制日报**：每日自动存档历史行情快照，支持随时回溯复盘及一键复制微信/备忘录日报。
